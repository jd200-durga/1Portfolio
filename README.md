# Durga Prasad — Portfolio Website

A responsive, single-page portfolio built with HTML, CSS, and vanilla JavaScript. It uses a dark editorial visual style, lime accents, custom CSS artwork, responsive layouts, and working external links.

## Run locally
Open `index.html` in a browser. No build step is required.

## Deploy
- **Netlify:** drag the project folder (or its ZIP contents) into Netlify Drop, or deploy it from a Git repository.
- **Vercel:** import the repository as a static site; no build command is needed and the output directory is the project root.
